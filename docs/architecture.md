# Architecture

syNC is a Python src-layout monorepo. Each package exposes a console script; most commands call `sync.chdir_to_git_root()` then run git/`gh`/Ollama work.

```text
sync CLI (sync | sync ui | sync init)
        │
        ├── workspace sync / pip|npm install
        ├── Flask UI  →  allowlisted modules via /run
        └── init      →  dependabot_sync + gitlint_sync

pr_sync      →  git/gh APIs, Ollama LLM, PR body, optional docs gen
release_sync →  version bump, CHANGELOG, tag, GitHub Release
dependabot_sync / gitlint_sync / gitflow_sync / version_sync / feature_sync / doc_sync
```

| Package | Script | Responsibility |
|---------|--------|----------------|
| `sync` | `sync` | Workspace sync, UI entry, combined init |
| `pr_sync` | `pr` | PR sync + LLM + Flask UI |
| `release_sync` | `rl` | Releases |
| `dependabot_sync` | `dp` | Dependabot YAML |
| `gitlint_sync` | `glnt`, `cm` | Commit lint + commit message helper |
| `doc_sync` | `doc` | Docs CLI wrapping `pr_sync.code_to_docs_generator` |
| `gitflow_sync` | `gf` | Gitflow check/start/finish |
| `feature_sync` | `fs` | Porter catalog for installing toolkit features |
| `version_sync` | `vs` | Version detect/bump/set/sync |

LLM calls go to local Ollama (`http://127.0.0.1:11434`) only. The UI `/run` endpoint accepts only an explicit script allowlist (`pr`, `rl`, `dp`, `glnt`, `cm`, `gf`, `fs`, `vs`, `doc`, `sync`).

Module guides generated by `doc` / `pr` under this folder are AI drafts and may drift from the code.

Maturity / hygiene requirements for this release: [maturity-hygiene-specification.md](maturity-hygiene-specification.md).
